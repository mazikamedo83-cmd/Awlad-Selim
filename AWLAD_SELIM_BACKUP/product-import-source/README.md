# مجلد استيراد ملفات الأصناف الأصلية (أبو سليم)
## AWLAD SELIM - Product Import Source Folder

هذا المجلد مخصص لحفظ ملفات الأصناف الأصلية المرفقة مثل:
- شيبسيات.txt
- مشروبات.txt
- ملفات البسكويت (tool.txt)
- ملفات CSV أو Excel

### قواعد الاستيراد الصارمة:
1. استخراج أسماء المنتجات والأكواد الأصلية فقط.
2. عدم تغيير الأكواد الأصلية.
3. ترك سعر الشراء فارغاً (0).
4. ترك سعر البيع فارغاً (0).
5. ترك رصيد الكميات فارغاً (0).
6. ترك الصور فارغة (لا يتم جلب صور عشوائية من الإنترنت).
7. منع تشغيل أي ملفات SQL أو PS1 أو برمجيات تنفيذية.
8. التحقق من التكرار وعرض شاشة معاينة تفصيلية قبل الاعتماد.
